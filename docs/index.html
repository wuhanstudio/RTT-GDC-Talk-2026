Are Neural Networks suitable for MCUs?

  • Neural Networks
    • Computation intensive (GPU)
    • Memory hungry
    • Floating Point
  • MCUs
    • Limited computation power (no GPU)
    • Limited memory (e.g., 256KB RAM)
    • INT32, INT16, INT8

Why is On-Device Training Important?

Data Distribution Shift

  • Evolving Environment
  • Sensor Degradation
  • User Personalization
The main reason is data distribution shift. If we train a model on a PC and then deploy the model on MCUs, the real-world data distribution may not be the same as the training data for several reasons: the environment is evolving, sensors will degrade over time, and people are different. For example, in the EMG dataset, the project Shengyu has been working on. The sensor measures the electrical activity of muscles and predicts the hand gesture. If we train the model on the server using data from a group of users, the model accuracy is 85%, but if we continue to train the model on the device using personal data, the accuracy can be improved to 96%. If we personalize the model for each user, we can achieve much better performance. The problem here is personal data is sensitive, and it cannot be uploaded to the server for training. We need to train on the device.
